# Tianqi Yang

Personal academic homepage for Tianqi Yang.

Published at: https://tianqi-yang-econ.github.io/

## Public Repository Policy

This repository is public because it is the source for a GitHub Pages site.
Keep it limited to files that should be visible on the public web.

Commit only deployable site assets, such as:

- `index.html`
- `style.css`
- `map.js`
- `world-data.js`
- `provinces-data.js`
- `robots.txt`
- `sitemap.xml`
- `cv.pdf`

Do not commit local maintenance notes, machine-specific paths, build scripts,
raw data, private drafts, proxy settings, credentials, or internal workflow
documentation.

## Indexing

The site exposes `robots.txt`, `sitemap.xml`, canonical metadata, Open Graph
metadata, and schema.org Person metadata. After major edits, submit:

- `https://tianqi-yang-econ.github.io/`
- `https://tianqi-yang-econ.github.io/sitemap.xml`

to Google Search Console and Bing Webmaster Tools.
